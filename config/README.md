# config/

Тут на сервері з'являються службові файли, яких немає в git:

- `users.php` — облікові записи адмінки (паролі лише у вигляді хешів);
- `setup-token.txt` — одноразовий код для першого входу, зникає після створення облікового запису;
- `login-attempts.json` — лічильник невдалих спроб входу.

Тека закрита з інтернету через `.htaccess`.
