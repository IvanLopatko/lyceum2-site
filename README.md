# Сайт Біляївського ліцею №2 — робочий зразок

Новий сайт ліцею на WordPress: власна тема **«Вітрила»** в кольорах емблеми, розділи за статтею 30 Закону «Про освіту», реєстр документів зі строками оприлюднення, сторінка «Профільна школа», новини, перенесені зі спільноти ліцею у Facebook.

**Подивитися:** посилання на GitHub Pages — у розділі «About» праворуч.

> Це демонстраційна копія. Частина текстів і цифр — зразкові, вони позначені плашкою «Зразок» і будуть замінені на фактичні. Пошукові системи цю копію не індексують.

## Що тут лежить

| Тека | Що це |
|---|---|
| `docs/` | Статична копія сайту для перегляду в браузері (її показує GitHub Pages) |
| `wp-content/themes/vitryla/` | Тема: шаблони, стилі, анімації |
| `wp-content/mu-plugins/` | Дані й логіка: документи, кадри, гуртки, строки оприлюднення, сторінки, імпорт новин |
| `tools/` | Скрипти: експорт статичної копії, обробка дописів із Facebook |
| `blueprint.json` | Налаштування для локального запуску |

## Як запустити локально

Потрібен Node.js 20+.

```bash
npx @wp-playground/cli@latest server --port 9400 --blueprint ./blueprint.json \
  --mount-before-install "$(pwd)/wp-content:/wordpress/wp-content"
```

Сайт відкриється на http://127.0.0.1:9400. Перед публікацією на справжньому хостингу треба видалити `wp-content/mu-plugins/0-vitryla-dev-host.php` і зразкові дані (кнопка в «Дані ліцею»).

## Оновити копію в `docs/`

```bash
python3 tools/export_static.py http://127.0.0.1:9400 docs
```
