# Сайт Біляївського ліцею №2

Власний сайт ліцею без WordPress і без бази даних: PHP 8.1+, вміст у JSON-файлах, адмінка для редагування.

**Подивитися:** статична копія на GitHub Pages (посилання — у розділі «About» праворуч). Адмінки й пошуку в копії немає; вона закрита від пошуковиків і має плашку «Зразок».

## Як влаштовано

| Тека | Що там |
|---|---|
| `index.php` | Єдина точка входу: сайт і адмінка (`/admin/`) |
| `app/` | Код: маршрути, шаблони, логіка строків за ст. 30, адмінка |
| `content/` | Увесь вміст: `pages/` (сторінка = файл), `news/` (новина = файл), `documents.json`, `staff.json`, `clubs.json`, `settings.json`, `profile-plan.json` |
| `uploads/` | Фото й PDF |
| `assets/` | Стилі, скрипти, шрифти (локально), значки, ілюстрації |
| `config/` | На сервері: облікові записи адмінки, сесії. **Не в git** |
| `docs/` | Статична копія для GitHub Pages |
| `tools/` | Перенесення з WordPress, експорт статичної копії, локальний запуск |

Сторінки складаються з блоків: абзац, заголовок, список, кроки, хронологія, картки, цифри, питання-відповіді, таблиця, виноска, кнопки, цитата, порівняння, міфи і факти, галерея та «живі» блоки (реєстр документів, люди, план профільної школи, відлік днів, контакти тощо). Усі редагуються мишкою в адмінці.

## Адмінка

- Вхід: `/admin/`. Паролі зберігаються лише як хеш, після 5 невдалих спроб — пауза 15 хвилин, усі форми захищені від підробки (CSRF).
- Розділи: огляд (строки документів, зразкові дані), сторінки, новини з фото, документи з PDF, кадри з фото, гуртки, налаштування (контакти, цифри, «Сьогодні в ліцеї», відповідальні), обліковий запис (пароль, доступи для редакторів).
- Фото при завантаженні зменшуються до 1600 px і перекодовуються; PDF перевіряються за вмістом.
- Перед кожною правкою попередня версія файлу кладеться в `content/.history/` (30 останніх).

## Запуск локально

З PHP 8.1+:

```bash
php -S 127.0.0.1:9600 tools/dev-router.php
```

Без PHP — через Node.js:

```bash
npx @wp-playground/cli@latest server --port 9600 --mount-dir "$(pwd)" /wordpress --wordpress-install-mode=do-not-attempt-installing --skip-sqlite-setup
```

## Перенесення на хостинг

1. Хостинг з PHP 8.1+ (розширення `gd`, `mbstring`, `json`, `fileinfo`), Apache або LiteSpeed, HTTPS.
2. Завантажити всі файли, крім `docs/` і `tools/`, у корінь сайту.
3. Відкрити `/admin/` — сайт попросить код із файлу `config/setup-token.txt` (його видно лише через файловий менеджер хостингу) і створить перший обліковий запис.
4. Прибрати зразкові дані кнопкою на огляді адмінки й дозволити індексацію пошуковиками.

## Оновити статичну копію в `docs/`

```bash
python3 tools/export_static.py http://127.0.0.1:9600 docs
```
